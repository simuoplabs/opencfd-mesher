# Simuop Labs // OpenCFD Studio (opencfd-mesher)

An open-source, cross-platform Finite Volume Method (FVM) and Finite Element Method (FEM) 3D CAD preparation and meshing studio built with C++17, Gmsh, OpenCASCADE, VTK, and Qt 6.
